## How I work

- **Model the data first** — the schema and its constraints carry the business rules.
- **Enforce access on the server** — every route checks who is calling and which tenant the data belongs to.
- **Make operations safe to repeat** — retries, double clicks and overlapping jobs never create duplicates.
- **Test the way attackers and real users behave** — cross-tenant access, wrong roles, malformed input, phone screens.
- **Ship operable software** — health checks, backups, error monitoring and a written deploy guide.
